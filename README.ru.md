# Мост из MAX в Telegram

Мост копирует сообщения между учётной записью MAX и ботом Telegram. Программа работает на вашем компьютере. Страница входа открывается только на этом компьютере.

## Требования

- Rust и Cargo, стабильный канал
- Токен бота Telegram
- Идентификатор Telegram каждого человека, которому можно пользоваться ботом

## Сборка

Надписи бота и страницы входа выбираются при сборке. Задайте `LANGUAGE=en` или `LANGUAGE=ru`. Сборка останавливается, если `LANGUAGE` не задана или имеет другое значение.

PowerShell:

```powershell
$env:LANGUAGE = "ru"
cargo build -p max-bridge --release
```

bash:

```bash
LANGUAGE=en cargo build -p max-bridge --release
```

Файл программы: `target/release/max-bridge`. В Windows это `target\release\max-bridge.exe`.

`LANGUAGE=en` включает английские надписи. `LANGUAGE=ru` включает русские надписи. Это кнопки бота, описания команд, статусные тексты и страница входа. Строки журнала остаются на английском.

Перед `cargo test` задайте то же значение. После смены `LANGUAGE` Cargo пересобирает мост.

## Настройка

До запуска программы создайте `var/bridge.env`. Git игнорирует `var/`. Не публикуйте этот каталог. В нём лежит сессия MAX.

```
TELEGRAM_BOT_TOKEN=123456:replace-me
TELEGRAM_ALLOWED_USER_IDS=123456789
MODE=Thread
```

Мост читает эти переменные из окружения или из `var/bridge.env`. Если значение задано в обоих местах, используется окружение.

| Переменная | Обязательна | Описание |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | Да | Токен из BotFather. |
| `TELEGRAM_ALLOWED_USER_IDS` | Да | Идентификаторы Telegram через запятую. Только эти люди пользуются ботом. |
| `MODE` | Нет | `Chat` или `Thread`. По умолчанию `Chat`. |

Необязательные пути: `MAX_VAR`, `MAX_ENV_PATH`, `MAX_SESSION_PATH`, `MAX_MAP_PATH`, `MAX_LINKS_PATH`, `MAX_RECEIPTS_PATH`, `MAX_TOPICS_PATH`, `MAX_OFFSET_PATH`, `MAX_SEEN_PATH`.

## Вход

1. Запустите программу.
2. Откройте бота в Telegram.
3. Выберите кнопку mini app: **Настроить**, если сессии MAX нет, или **Добавить контакт**, если сессия живая. Можно также отправить `/setup`.
4. Введите номер телефона, затем код из звонка MAX.
5. Если MAX запрашивает облачный пароль, введите его.

Mini app работает на этом компьютере: `https://127.0.0.1:8788/app`. Без живой сессии MAX открывается вход, с живой сессией — добавление контакта. Запасной вход в браузере: `http://127.0.0.1:8787`. Надписи в этом разделе соответствуют сборке с `LANGUAGE=ru`.

PowerShell:

```powershell
$env:LANGUAGE = "ru"
cargo run -p max-bridge --release
```

bash:

```bash
LANGUAGE=en cargo run -p max-bridge --release
```

`cargo run` передаёт `LANGUAGE` компилятору. Уже собранный файл хранит язык той сборки.

## Режимы

`Chat` копирует все чаты MAX в один чат Telegram. Имя контакта стоит над сообщением.

`Thread` создаёт тему Telegram для каждого чата MAX. Ответы остаются в этой теме. Команды истории работают только в этом режиме.

В режиме `Thread` кнопка mini app всегда на месте: **Настроить** без живой сессии MAX, **Добавить контакт** при живой сессии. После подключения MAX бот также показывает:

- **Загрузить историю** (`/history`) дописывает чаты, которых ещё нет.
- **Перечитать историю** (`/reread`) удаляет темы и загружает их заново.
- **Выйти** (`/logout`) сбрасывает сессию MAX и спрашивает, удалить ли загруженные сообщения.

Чат «Избранное» в MAX копируется с подписью **Favorites** или **Избранное**, в зависимости от `LANGUAGE`. Живые сообщения, которые вы отправляете из другого клиента MAX, копируются только в этом чате. Загрузка истории включает ваши сообщения и начинает их с **you** или **ты**.

Когда оба сервиса отдают файл, фотографии, голосовые сообщения и видео копируются в обе стороны.

## Статусы сообщений

У Telegram-бота нет нативных галочек доставки. Мост ставит реакции на ваши исходящие сообщения:

- ⚡ — MAX принял сообщение (`sent`)
- 👍 — доставлено собеседнику (`arrived`)
- 👀 — собеседник прочитал в MAX (`read`)

На входящем сообщении из MAX поставьте реакцию 👀 в Telegram, чтобы отметить его прочитанным в MAX. Мост не помечает сообщения прочитанными сам при пересылке.

После реконнекта MAX мост обновляет незавершённые исходящие статусы по водяным знакам прочтения чата и повторяет отложенные отметки прочтения.

Необязательный путь: `MAX_RECEIPTS_PATH` (по умолчанию `var/receipts.json`).

## Состав проекта

- `crates/max-client` — клиент MAX.
- `crates/max-bridge` — бот Telegram и страница входа.
